演示顺序（demo-design.md 7.6，约 8-10 分钟）

  1. 网页端：admin 一键登录 → 看板（一期 4 指标 + 二期扩展）
  2. 包裹管理：城东驿站 + 在库待取 + 近 7 天 → 翻页 / 详情抽屉（脱敏收件人）
  3. 同步任务：找到失败批次 → 看日志 → 重试（失败 → 待领取 → 成功）
  4. 工单管理：切「超时未处理」Tab → 打开工单 → 指派站长 → 转「处理中」
  5. 通知中心：看到上一步自动生成的「工单指派」通知（跨页联动）
  6. 移动端（DevTools 切 iPhone 14 Pro）：管理端总览 → 趋势切 30 天 → 排行切换排序 → 异常预警
  7. 「我的」切换为城东驿站站长：数据范围收敛为本站
  8. 工作台 → 本站包裹 → 取件核销 → 填入演示运单号 → 确认取件
  9. 工单列表 → 处理工单 → 填处理记录 → 标记已解决 → 通知页二次联动
  10. 回网页端刷新看板与工单页：今日取件 +1、工单已解决（三端数据一致性）
