## 5. V24 回填：群机器人 Webhook 能否推送到外部客户群（POC-03，本批未覆盖）

> ADR 原定义：在专用测试外部群配置机器人并实际发送。阻塞级别：**最高**，责任角色：后端工程师。
> **本批范围说明**：本批只做 POC-01/02/05，**不包含 POC-03**，故 V24 的实测结论本次无法给出，标记为「顺延」。

| 项 | 填写 |
|----|----|
| 本批是否覆盖 POC-03 | 否（本批仅 01/02/05） |
| 现有证据（已核实，供参考） | 企业微信帮助中心 `docid=14931` 与官方社区答复均表明「群机器人只支持内部群，外部群无法设置群机器人」 |
| 倾向性判断（仅供参考，非实测） | 倾向「外部群不支持群机器人」→ S3 主通道存在失效风险 |
| 是否需补做 POC-03 | 建议是（需先有可用外部测试群；用户已确认目前只有内部群可测） |
| 顺延说明 | 待具备外部测试群条件后补做，或直接采信官文并调整 S3 通道设计 |
| 关联风险 | K23（外部客户群 Webhook 不可推送，级别：高） |
| ADR 章节回填位置 | 第 19 章 V24 / 第 20 章 K23 / 第 5.2 章 T1 适用性 |
